# CPP Project

Simple C++ desktop application built with **SDL3** and **Dear ImGui**, configured to build with **CMake**, **Ninja**, and dependency management via **vcpkg**.

## Tech Stack

* **Language:** C++
* **Window & Input:** [SDL3](https://github.com/libsdl-org/SDL)
* **GUI:** [Dear ImGui](https://github.com/ocornut/imgui)
* **Build System:** CMake + Ninja
* **Dependency Manager:** vcpkg
